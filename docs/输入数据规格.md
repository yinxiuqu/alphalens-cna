# 输入数据规格

> **本文是 alphalens-cna 的数据契约。**
> 任何数据源，只要转成下面这些结构，就能进本库。
> 反过来，**不符合规格的输入会被拒绝运行，不产出任何数字**。

---

## 0. 一句话

**所有输入都是 pandas `DataFrame`，统一「长表 + `MultiIndex(date, asset)`」。**

没有自定义容器类，没有 pickle，没有二进制格式。你能 `print()` 出来，就能喂进来。

---

## 1. 通用约定

| 项 | 规定 | 理由 |
|---|---|---|
| **索引** | `MultiIndex`，level 0 = `date`，level 1 = `asset` | 与 alphalens 的 factor 一致；长表能装多字段 |
| `date` | `datetime64[ns]`，**tz-naive** | 全库统一，避免时区混用 |
| `asset` | `str`，**6 位代码**（如 `'600519'`） | 不带交易所后缀；后缀由适配器剥掉 |
| **比率类** | **小数**（`0.05` = 5%） | 避免 `5` vs `0.05` 的歧义 |
| **金额类** | **元** | 人民币元，不是千元/万元 |
| **成交量** | **手** | 1 手 = 100 股 |
| **价格** | **元**，且 `> 0` | 负价/零价直接拒绝 |
| 缺失 | **`NaN`**，不要用 `-1` / `''` / `None` 填充 | 库靠 NaN 识别缺失 |
| 排序 | 不要求有序；库内部会排 | 但**索引必须唯一** |

## 2. 八个契约对象

### 2.1 `FactorPanel` —— 待检验的因子 ★必填

```python
index   : MultiIndex(date, asset)          # 必须唯一
columns :
    value          float64    因子值
    available_at   datetime64 该值【何时可知】
```

**示例**
```
                                value   available_at
date                asset
2020-04-28          600519      0.312   2020-04-28
2020-04-28          000001      0.087   2020-04-28
```

**`available_at` 是硬闸门**：校验 `available_at <= date`。
财报因子应填**公告日 + 1 交易日**（本次 ROE 用的 `avail_314` 就是这个语义）。

> **为什么必须有**：本次实测踩过 —— 用 `avail_314` 全靠自觉，忘一次就是前视偏差。

---

### 2.2 `PricePanel` —— 行情 ★必填，**三价并存**

```python
index   : MultiIndex(date, asset)
columns :
    # ── 原始不复权价（只用于制度判定）──
    raw_open       float64   元
    raw_high       float64   元
    raw_low        float64   元
    raw_close      float64   元
    prev_close     float64   前一交易日的 raw_close，元

    # ── 复权因子（唯一真相）──
    adj_factor     float64   累计复权因子，> 0

    # ── 复权价（派生，只用于收益计算）──
    adj_open       float64   = raw_open  × adj_factor
    adj_high       float64
    adj_low        float64
    adj_close      float64

    # ── 成交 ──
    volume         float64   手
    amount         float64   元
```

#### ⚠️ 三条硬规则（写进校验，违反即拒绝）

| # | 规则 | 依据 |
|---|---|---|
| **1** | **制度判定**（涨跌停价、报价单位、ST）**只允许读 `raw_*`** | 实测 600519 在 2016-08-26 的涨停价：用 raw 算 **333.31**（对），用当时的前复权价算 **270.01** —— **差 23%** |
| **2** | **收益计算只允许读 `adj_*`** | 复权价才能跨除权日连续 |
| **3** | **只给 `adj_*`、不给 `raw_*` + `adj_factor` ⇒ 拒绝** | 缺 raw 就没法判涨跌停；缺因子就没法换口径 |

#### `adj_factor` 的口径

**不要求绝对值正确，只要求两件事：**

1. **单调性** —— 因子在除权日单调变化（配股可能使其下降，属正常）
2. **收益正确** —— 与另一种口径算出的收益 **1e-10 一致**

> 因为**任何常数缩放都不影响收益**：`adj(t₂)/adj(t₁)` 里的常数会约掉。
> 所以「后复权（绝对值）」与「前复权（归一到末位=1）」**在收益上完全等价**。

#### 两种口径都支持

```python
acna.load_prices(adjust_source='computed')   # 默认：从 raw + xdxr 现算后复权
acna.load_prices(adjust_source='stored')     # 快：直接读现成的复权因子
```

**两者互为交叉验证** —— 收益必须一致，不一致即说明复权数据有问题（见 §4 不变量）。

---

### 2.3 `Tradability` —— 可成交性 ○可选

不给就由库从 `PricePanel` + `Calendar` 推断（精度略低）。

```python
index   : MultiIndex(date, asset)
columns :
    suspended        bool      停牌
    is_st            bool      名称含 ST/*ST → 涨跌停 5%
    listed_days      int32     上市第几个交易日（1 = 首日）
    limit_up_price   float64   涨停价，元（可选，不给则由库自算）
    limit_down_price float64   跌停价，元（可选）
```

**⛔ 不要给 `close_at_limit` 这种"收盘在板"字段来判开盘成交。**
`limit_status` 是**收盘**状态，用它门控**当日开盘**成交 = 前视。

---

### 2.4 `Calendar` —— 交易日历 ★必填

```python
pd.DatetimeIndex     # 有序、唯一、tz-naive
```

**自持，不依赖 pandas `freq` 推断。**
> 依据：alphalens 在非日频索引上直接崩（`Inferred frequency None ... frequency C`）。

---

### 2.5 `Universe` —— as-of 股票池 ★必填

```python
index   : MultiIndex(date, asset)
columns :
    in_universe   bool
```

**防生存者偏差的硬闸门**：用「今天的成分股」回测历史 → **拒绝**。
退市股应当在它们**还活着的时候**出现在池子里。

---

### 2.6 `Grouping` —— 分组/行业 ○可选

```python
index   : MultiIndex(date, asset)
columns :
    group   str      行业代码 / 分组标签
```

用于：行业中性化、分组统计。
**必须是 as-of 的**（按当日实际所属行业，不是最新行业）。

---

### 2.7 `Exposures` —— 控制变量 ○可选

**但做中性化或 Fama-MacBeth 时必填。**

```python
index   : MultiIndex(date, asset)
columns :
    <任意多个>   float64     如 ln_mv, turnover_rate, pb ...
```

**示例**
```
                        ln_mv   turnover_rate      pb
date        asset
2020-04-28  600519    28.13          0.0042    9.87
2020-04-28  000001    26.41          0.0118    0.72
```

---

### 2.8 `Events` —— 事件日 ○可选

**仅事件研究需要。**

```python
index   : MultiIndex(date, asset)
columns :
    event_type   str      事件类型标签，如 'earnings'
```

只保留**事件发生日**那一行（不是每日一行）。

## 3. 目录约定（parquet 数据源）

`adapters/input/parquet.py` 认下面这个布局。**任何人的数据摆成这样，零代码即可读。**

```
mydata/
├── prices.parquet            # 列同 §2.2（index 需 reset 成列：date, asset, ...）
├── xdxr.parquet              # 除权事件（用于现算复权）
│                             #   date, asset, category, fenhong, peigu,
│                             #   peigujia, songzhuangu
├── tradability.parquet       # 可选，列同 §2.3
├── universe.parquet          # 可选，列同 §2.5
├── exposures.parquet         # 可选，列同 §2.7
├── events.parquet            # 可选，列同 §2.8
└── factors/
    ├── roe.parquet           # 每个因子一个文件：date, asset, value, available_at
    ├── momentum_20.parquet
    └── ...
```

**磁盘上的 parquet 用普通列**（`date` / `asset` 是列，不是索引）—— 方便用 DuckDB / pandas 直接看。
**库读进来后才转成 MultiIndex。**

用法：

```python
import alphalens_cna as acna

px  = acna.load_prices(source='parquet', root='~/mydata')
roe = acna.load_factor('roe', source='parquet', root='~/mydata')
```

## 4. 校验规则（防线 1：违反即拒绝运行）

| # | 校验 | 拒绝条件 |
|---|---|---|
| 1 | **前视** | `available_at > date` |
| 2 | 索引唯一 | 重复 `(date, asset)` |
| 3 | 价格为正 | `raw_* <= 0` 或 `adj_* <= 0` |
| 4 | **复权完整** | 有 `adj_*` 却缺 `raw_*` 或 `adj_factor` |
| 5 | **复权自洽** | `adj_* ≠ raw_* × adj_factor`（容差 1e-8） |
| 6 | 股票池 as-of | 检测到「用当前成分回测历史」 |
| 7 | 日历 | `date` 不在 `Calendar` 上 |
| 8 | 时区 | 索引 tz-aware |
| 9 | 两口径一致 | `computed` 与 `stored` 的收益差 > 1e-10 |

**校验失败会抛异常并说明是哪一行、哪个字段** —— 不产出任何数字。

## 5. 最小可运行示例

```python
import numpy as np
import pandas as pd
import alphalens_cna as acna

# ── 3 只股票 × 5 个交易日 ──
dates  = pd.bdate_range('2024-01-02', periods=5)
assets = ['600000', '000001', '300750']
idx = pd.MultiIndex.from_product([dates, assets], names=['date', 'asset'])

prices = pd.DataFrame({
    'raw_open':   [10.0, 12.0, 30.0] * 5,
    'raw_close':  [10.2, 12.1, 30.5] * 5,
    'raw_high':   [10.3, 12.2, 30.8] * 5,
    'raw_low':    [ 9.9, 11.9, 29.8] * 5,
    'prev_close': [10.0, 12.0, 30.0] * 5,
    'adj_factor': [1.0] * 15,          # 无除权 → 因子恒为 1
    'volume':     [1e5] * 15,
    'amount':     [1e7] * 15,
}, index=idx)
prices['adj_open']  = prices['raw_open']  * prices['adj_factor']
prices['adj_close'] = prices['raw_close'] * prices['adj_factor']
prices['adj_high']  = prices['raw_high']  * prices['adj_factor']
prices['adj_low']   = prices['raw_low']   * prices['adj_factor']

factor = pd.DataFrame({
    'value':        [0.5, 0.3, 0.8] * 5,
    # ⚠️ 索引顺序是 (d0,a0),(d0,a1),(d0,a2),(d1,a0)…
    #    所以日期要【按股票数重复】，不是 list(dates)*3
    'available_at': np.repeat(dates, len(assets)),
}, index=idx).sort_index()

calendar = pd.DatetimeIndex(dates)
universe = pd.DataFrame({'in_universe': True}, index=idx)

# ── 跑一次分析 ──
# ⚠️ 本库**没有** `acna.analyze` / `acna.Spec` —— 那两个名字只出现在设计稿的
#    目标 L1 一行式里（见 docs/cases/alphalens-cna总体设计.md），从未实现。
#    现成的显式入口是 `build_report`：清洗 → 体检 → IC/分层 → 结论，一次拿全。
#
# ⚠️ 上面那块 5 天 × 3 只只够演示**列格式** —— 它的价格不随时间变，没有收益，
#    真拿去跑分析会报「IC 全是 NaN（样本不足以判断）」。下面是够用的规模：
rng = np.random.default_rng(0)
D2, A2 = pd.bdate_range('2023-01-02', periods=60), [f'{i:06d}' for i in range(20)]
idx2 = pd.MultiIndex.from_product([D2, A2], names=['date', 'asset'])
close2 = (np.tile(rng.uniform(5, 50, len(A2)), len(D2))
          * np.exp(np.cumsum(rng.normal(0, .004, len(idx2)))))
px2 = pd.DataFrame({'raw_close': close2}, index=idx2)
for c, k in (('open', 1.0), ('high', 1.005), ('low', .995)):
    px2[f'raw_{c}'] = close2 * k
px2['prev_close'] = px2.groupby(level='asset')['raw_close'].shift(1).fillna(px2['raw_close'])
px2['adj_factor'] = 1.0                       # 无除权 → 因子恒为 1
for c in ('open', 'high', 'low', 'close'):
    px2[f'adj_{c}'] = px2[f'raw_{c}']
px2['volume'] = 1e5
f2 = pd.DataFrame({'value': rng.normal(size=len(idx2)),
                   'available_at': idx2.get_level_values('date')}, index=idx2)
u2 = pd.DataFrame({'in_universe': True}, index=idx2)

res = acna.build_report(
    acna.FactorPanel(f2),                # 包一层 = 先过契约，早报错
    acna.PricePanel(px2),
    acna.Calendar(pd.DatetimeIndex(D2)),
    horizons=(1, 3), quantiles=3,        # 档数不能超过每期股票数
    universe=acna.Universe(u2), name='demo',
)

print(res.verdict.significant)     # 校正后是否显著
print(res.verdict.p_adjusted)      # BHY 校正后 p 值
print(res.verdict.n_trials)        # 一共测过几个假设
```

## 6. 私有数据源怎么接

**不要改库。** 写个适配器放 `examples/`：

```python
# examples/my_adapter.py
from alphalens_cna.adapters.input.base import InputAdapter
from alphalens_cna import PricePanel, FactorPanel

class MyAdapter(InputAdapter):
    def prices(self, start, end) -> PricePanel:
        df = ...        # 从你的数据库/文件读
        return PricePanel(df)

    def factor(self, name, start, end) -> FactorPanel:
        df = ...
        return FactorPanel(df)
```

```python
px = acna.load_prices(source=MyAdapter())
```

> 库更新时只要**协议没变**，你的适配器一行都不用改。
> 核心包里**永远不会出现任何人的私有目录名**。

## 附：M2 新增模块的接口速查

> 全部接受 `MultiIndex(date, asset)`；输入 `Series` 返回 `Series`，
> 输入 `DataFrame`/清洗结果则整体返回同型。**行数一律不变**。

### 预处理 `alphalens_cna.preprocess`

```python
acna.winsorize(factor, method='mad'|'sigma'|'quantile', n=3.0, limits=(.01,.99))
acna.standardize(factor, method='zscore'|'rank'|'demean')
acna.neutralize(factor, exposures=<DataFrame|list>, groups=<Series>)   # 二选一
acna.orthogonalize(factor, others)          # = neutralize(exposures=others)
acna.combine([f1, f2], weights=[...])       # 先各自标准化再加权，权重自动归一
acna.preprocess_log(obj)                    # 每步改了多少行、跳过几个截面
```
推荐顺序：`winsorize → standardize → neutralize → combine`。

### 尾部统计 `alphalens_cna.analysis.tail`

```python
acna.value_at_risk(r, level=.05)      # 左尾门槛（顺序统计量，不插值）
acna.cvar(r, level=.05)               # 尾部均值；== expected_shortfall
acna.downside_deviation(r)            # 只算亏损那侧
acna.crash_stats(r, level=.05, threshold=-.5)
acna.tail_by_quantile(clean_or_df, level=.05, threshold=None)   # index=(h,q)
acna.crash_spread(clean_or_df, threshold=-.5)                   # QN−Q1 命中率差 + NW t
```
⚠️ 分位门槛（`threshold=None`）下每个分位命中率必然 ≈10%，只反映尾部**集中度**；
判断"某组更容易炸"**必须传绝对门槛**。

### 事件研究 `alphalens_cna.analysis.event`

```python
w = acna.align_event_windows(prices, events, calendar,
                             window=(-5, 20), base_day=0, benchmark=None)
w.summary()                                  # 逐相对日：均值/胜率/t_naive/t_ct
acna.event_path_by_group(w, 'surprise', quantiles=5)
```
`events` 需 `(date, asset)` 索引且含 `event_type`（`Events` 契约）。
`t_ct` = 日历时间组合法，**事件聚集时看它，不要看 `t_naive`**。

### 截面回归 `alphalens_cna.analysis.regression`

```python
acna.cross_sectional_regression(y, X, add_constant=True, min_obs=10)
acna.fama_macbeth(y, X, horizon=21)          # .coef / .summary / str()
acna.shanken_inflation(mean_coef, factor_cov)  # 默认不做，要用显式调
```

### 诊断量 `alphalens_cna.inference`

```python
acna.rank_stability(factor)          # RRE ∈[0,1]，排名结构稳定性
acna.rank_entropy_summary(factor)    # + 分布熵 + 退化/噪声/不更新提示
acna.pfs(series, n_draws=200)        # PFS ∈[0,1]，扰动鲁棒性
acna.robustness_report(series, modes=(...), fracs=(.5,.7,.9))
```
