## 一、口径对账（先做，这是合并的闸门）

任务：给 250 只退市股补 ROE。**但现有 PIT 的 `roe` 不是 tushare 的 `roe`。**

600519 对账 55 个报告期：

| 候选口径 | 最大差 | 中位差 | 完全一致 |
|---|---|---|---|
| tushare `roe` | 6.03 | 0.65 | **0/55** |
| tushare `roe_waa`（加权平均） | 6.03 | 0.77 | 0/55 |
| tushare `roe_dt`（扣非） | 6.35 | 0.77 | 0/55 |
| tushare `roe_yearly`（年化） | 33.31 | 13.77 | 0/55 |
| **自算：字段 096 ÷ 271 × 100** | **0.0005** | 0.0003 | **55/55** ✅ |

结论：PIT 的 `roe`（gpcw 字段 197）=

```
roe = 累计归母净利润 ÷ 期末归母净资产 × 100
```

**不年化、非加权平均**。所以补数据根本不需要 tushare 的财务比率，只要两个原始科目：

```
income.n_income_attr_p                    → 归母净利润（累计）
balancesheet.total_hldr_eqy_exc_min_int   → 期末归母净资产
```

### 口径闸门（19 只在市股 × 813 个报告期）

| 版本 | 差 < 0.01 的比例 | 最大差 |
|---|---|---|
| 初版（净资产 ≤ 0 记 NaN） | 98.52% | **176.52** |
| **对齐 gpcw（净资产 ≤ 0 记 0）** | **99.38%** | **0.25** |

那 176.5 的巨差是怎么来的 —— 000505 净资产 −3.96e7，自算 ROE = −176.5，
而 **gpcw 给的是 0.0000**。也就是说：**gpcw 用 0 编码"无定义"**。照抄这个约定
才能合并；剩余 5 期差异（0.03–0.25）是修正版本差异，属数据本身的不确定性。

## 二、`roe = 0` 一律视为缺失（按你的判断）

**业务依据**：ROE = 净利润 / 净资产，要恰好等于 0 得净利润**精确为 0** —— 现实中不会发生。
所以 0 是占位，不是真值。

PIT 全表 303,318 行里 `roe == 0` 有 **3,118 行（1.03%）**，拆开看三类：

| 成因 | 行数 | 占比 | 含义 |
|---|---|---|---|
| 净资产 < 0 | 2,458 | 78.8% | ROE 数学上无定义 |
| 净资产 > 0 | 643 | 20.6% | 未披露占位 |
| 净资产 = 0 / 未知 | 17 | 0.5% | 无定义 |
| **合计置 NaN** | **3,118** | | **涉及 705 只在市股** |

补入退市股后：**4,410 行（1.41%）→ NaN，涉及 838 只股票**。

不修正的后果（这正是体检层抓到的那个告警）：这批票的因子值被读成 0（= 截面中位水平），
而它们其实是**净资产为负的困境公司** —— 恰恰是 ROE 因子最该识别的样本；
更糟的是因子值会连续几十个月冻结在 0（"因子冻结 25–42 期"的来源）。

> 实现上放在**读取阶段**（`load_pit(zerofix=True)`）而不是写盘阶段，
> 所以既修了问题，又保住了与 PIT 原始口径的一致性、跑得出三段对照。

## 四、为什么会变弱（机制诊断）

**退市股确实是差公司**（91 个调仓日全样本）：

| 组 | 观测 | ROE 中位 | 252 天收益均值 | 收益标准差 | \|收益\|>100% |
|---|---|---|---|---|---|
| 在市股 | 343,246 | 2.73 | **+15.28%** | 58.8% | 5.9% |
| 退市股 | 8,559 | **0.42** | **−7.92%** | 51.7% | 2.8% |

ROE 分位分布：**45.7% 的退市股落在最低分位 Q1**（Q5 只有 9.5%）。

**但 RankIC 看不到它们的崩盘。** 按"距该股最后交易日"分组：

| 退市股的阶段 | 观测 | h=21 均值 | h=21 中位 | **h=252 实现率** |
|---|---|---|---|---|
| 最后 3 个调仓日 | 692 | **−10.49%** | −8.06% | **仅 14%** |
| 最早 3 个调仓日 | 692 | +13.16% | +6.58% | 93% |
| （在市股对照） | 398,235 | +1.81% | +0.11% | 86% |

**这就是全部原因**：退市股最后一段时间确实在崩（一个月 −10.5%），
但**持有期越长，崩盘越落在窗口外** —— h=252 时最后 3 期只有 14% 还能算出收益，
86% 因为"股票已经没了"而被清洗掉。

于是长周期 IC 看到的是**被截断（censored）的子样本**：能留下 252 天收益的退市股，
恰恰是那些还没走到尽头的。**最惨的一段被结构性丢弃**，而它们本该是负向因子最强的证据。

## 五、结论与下一步

1. **"补退市股"是必要条件，不是充分条件。** 行情和财务都补上了（5,506 → 5,801 只），
   存活偏差在**数据层面**已消除（体检层：242/5,247 中途结束 = 4.61% ✅），
   但在**长持有期的因子检验层面**仍有一个缺口。
2. **缺的是"退市收益约定"（delisting return convention）**：
   对窗口内退市的样本，用一个明确规则补上末段收益，而不是 `dropna`。
   A 股有退市整理期真实成交价，可用"最后交易日收盘/退市整理期均价"，
   或保守折扣；关键是把规则**写进契约**并让清洗账记上一类 `delisted_window`。
   这一步做完，h=252 的 IC 才算真正无存活偏差。
3. **当前的 ROE 结论**：修正后 |RankIC| 全线走弱约 20%，
   h=252 为 −0.0473。结合此前的多重检验结果（BHY 校正后不显著），
   **"ROE 在 A 股月频上不构成显著因子"这个结论只会更稳，不会翻转。**
4. 退市股财务数据只补了 2016 年以后的报告期（面板起点）。若将来把面板前推，
   重跑 `build` 并把 `START` 改早即可（脚本支持断点续跑）。
