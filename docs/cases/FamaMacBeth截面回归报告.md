# Fama-MacBeth 截面回归报告

**方法**：石川《因子投资：方法与实践》标准流程 ｜ **区间**：2019-01 ~ 2026-07，**91 个月度截面**
**平均截面**：4370 只 ｜ **去极值**：MAD(3) ｜ **标准化**：横截面 z-score ｜ **因变量**：未来 21 交易日收益

> **先说结论：能做，而且做出来的东西比分组排序（alphalens）多一层信息 ——
> 它揭示了 ROE 那个"负向"结论其实是规模效应混淆出来的。**

---

## 一、为什么这件事值得单独做

| | 分组排序（alphalens） | 截面回归（Fama-MacBeth） |
|---|---|---|
| 能回答 | "高 ROE 组合 vs 低 ROE 组合，谁跑赢" | "**控制其他因子后**，ROE 还有没有独立溢价" |
| 因子间混淆 | ❌ 无法剥离 | ✅ 天然剥离 |
| 输出 | 分层收益、IC | **因子收益率 γ 与其 t 值** |
| alphalens 支持吗 | ✅ | ❌ **完全没有** |

**alphalens 一行截面回归都没有。** 这是它作为"因子分析库"最大的功能缺口。

## 二、因子相关矩阵（先看混淆程度）

| | ROE | PB | lnMV | 换手 |
|---|---|---|---|---|
| **ROE** | 1.000 | 0.078 | **0.360** | −0.042 |
| **PB** | 0.078 | 1.000 | 0.123 | 0.275 |
| **lnMV** | **0.360** | 0.123 | 1.000 | −0.168 |
| **换手** | −0.042 | 0.275 | −0.168 | 1.000 |

**ROE 与 lnMV 相关 0.360** —— 高 ROE 公司偏向大市值。这个 0.36 就是后面所有故事的根源。

## 三、核心结果：三种设定下的因子收益率 γ

**月度，次日开盘口径（close 口径结果几乎相同）**

| 设定 / 因子 | γ 均值 | t 朴素 | **t 修正(NW)** | γ>0 比例 |
|---|---|---|---|---|
| **A 单因子 · ROE** | **−0.0021** | −1.31 | −1.18 | 38.5% |
| **B 多因子 · ROE** | **+0.0003** | 0.20 | **0.18** | 53.8% |
| B 多因子 · PB | −0.0002 | −0.10 | −0.10 | 47.2% |
| **B 多因子 · lnMV（规模）** | **−0.0063** | −3.50 | **−3.69** | 37.4% |
| **B 多因子 · 换手** | **−0.0044** | −2.17 | **−3.26** | 42.9% |
| **C 正交化 · ROE** | **+0.0003** | 0.20 | **0.18** | 53.8% |

平均 R² = 0.065

## 四、三个关键发现

### 4.1 ROE 的"负向"是规模效应混淆出来的

```
设定 A（只用 ROE）      γ = −0.0021   ← 负
设定 B（加 lnMV 控制）   γ = +0.0003   ← 符号翻正！
```

**同一个因子，只因多放了一个规模变量，符号就反了。**

解释：高 ROE 的公司平均市值更大（相关 0.36），而在 A 股**小市值长期占优**
（lnMV 的 γ = −0.0063，t = −3.69，高度显著）。
所以"高 ROE 组合跑输"**并不是 ROE 本身不好，而是它替你选了一批大市值股票**。

> ⚠️ 这条直接改写了上一份报告（月度调仓版）的解读。
> 那里我写的是"高 ROE 越贵、越容易跑输"，**只对了一半** —— 更准确的说法是
> **"单看 ROE 会顺带买到大规模，而大规模在 A 股是拖累"**。

### 4.2 控制之后，ROE 本身没有独立信息

```
设定 B · ROE   γ = +0.0003,  t_NW = 0.18    ← 完全为零
设定 C · 正交化 γ = +0.0003,  t_NW = 0.18    ← 与 B 完全一致（理论预期）
```

**γ 不显著、方向为正但量级几乎为零。**
所以 ROE 在月度频率上**既不是正向 alpha，也不是有效的负向筛选条件** —— 它就是没有增量信息。

设定 C（先对控制变量回归取残差）与设定 B 结果**逐位一致**，这是一个很好的自洽性检验：
正交化后的单因子回归 ≡ 多因子回归中该因子的系数。

### 4.3 真正显著的是规模和换手

| 因子 | γ（月） | t_NW | 解读 |
|---|---|---|---|
| **lnMV** | **−0.63%** | **−3.69** | 小市值月均多赚 0.63%，A 股规模效应显著 |
| **换手率** | **−0.44%** | **−3.26** | 低换手月均多赚 0.44%，流动性/情绪溢价 |
| PB | −0.02% | −0.10 | 价值因子在这个窗口无效 |
| ROE | +0.03% | 0.18 | 无 |

**在这个窗口里，A 股有效的不是质量（ROE/PB），而是规模和流动性。**

## 六、这对 alphalens-cna 的设计意味着什么

**截面回归必须作为一等公民内置。** 具体能力清单：

| 能力 | 说明 | alphalens |
|---|---|---|
| Fama-MacBeth 两阶段回归 | 逐期横截面 OLS + γ 时序推断 | ❌ |
| **因子收益率 γ 与其 t 值** | 这才是因子"赚不赚钱"的直接度量 | ❌ |
| 多因子控制 | 剥离因子间混淆 | ❌ |
| 正交化 | 因子对控制变量回归取残差 | ❌ |
| 相关矩阵 / VIF | 共线性诊断 | ❌ |
| 标准流程 | MAD 去极值 → z-score → 回归 | ❌ |
| Newey-West 修正 | 月度重叠的自相关 | ❌ |

**本次实测的教训直接支持了设计文档的"防线"思路**：
如果只做分组排序（alphalens 唯一会做的），我会得出
"高 ROE 跑输、所以 ROE 是负向因子"——**而这是错的**。
截面回归一控制规模，符号就翻了。

> **因子间混淆是分组排序的结构性盲区。** 这比任何一个已知 bug 都更影响结论的正确性。
