## 一、实现：三种约定 + 一条关键区分

`ReturnModel` 新增两个字段：

```python
ReturnModel(entry='same_open', exit_price='open',
            delist_policy='last_price',   # 'nan' | 'last_price' | 'haircut'
            delist_return=-0.30)          # 仅 haircut 用
```

| 约定 | 含义 | 台账 |
|---|---|---|
| `'nan'`（默认） | 保持旧行为：剔除 | `delisted_dropped` |
| `'last_price'` | 按**最后成交价**清算，之后视为现金（收益 0） | `delist_filled` |
| `'haircut'` | 最后成交价再乘 `1+delist_return`（Shumway 式） | `delist_filled` |

### ★ 关键区分：退市 ≠ 窗口内停牌

判据是**"该票在持有期末之后是否再也没有任何价格"**：

* 再也没有 → 退市/被吸收合并 → 可按约定清算
* 之后还有（只是期末没复牌）→ **停牌**，仍按缺失处理

混掉的后果：把停牌股按停牌前的旧价"清算"，等于凭空冻结一个过时价格。
`tests/test_delist.py::test_suspension_inside_window_is_not_delisting` 钉住这条。

### 防线

| 检查 | 结果 |
|---|---|
| 手算已知答案 | `last_price` → 8/10−1 = **−0.2000**；`haircut −30%` → 8×0.7/10−1 = **−0.4400** ✅ |
| 不改变未退市样本 | 三种约定下 A/C 的收益**逐位相同** ✅ |
| 折扣 0 ≡ `last_price` | 差 < 1e-15 ✅ |
| 非法参数 | 抛 `ContractError` ✅ |
| **对拍仍然逐位相同** | 默认 `nan` 下与 alphalens 三量 **0.000e+00** ✅ |
| 台账可归因 | `delist_filled` / `delisted_dropped` 分类计数 ✅ |

## 三、机制：新增观测确实是"最该有的证据"

新增的 1,405 条观测（h=252 视角下 1,767 条）画像：

| 指标 | 新增观测 | 全体样本 |
|---|---|---|
| 落在 **ROE 最低分位 Q1** | **1,245 条（88.6%）** | 20% |
| 252 天收益 **均值** | **−62.89%** | +8.74% |
| 252 天收益 **中位** | **−77.78%** | — |

**低 ROE + 暴跌，正是负向因子最强的证据。** 但 IC 却变弱了 —— 逐日对账：

| | 数值 |
|---|---|
| 受影响日期 | **80/80 天全部受影响**（每天新增 18–46 条） |
| 受影响日的 IC | −0.0473 → −0.0400（平均变化 **+0.0073**，中位 +0.0052） |
| 最典型的一天 | 2022-07-29：新增 31 条，IC −0.2141 → −0.1948 |

### 为什么"最强证据"反而削弱 IC

因为 **Spearman 秩相关度量的是全样本的成对单调性**，而新进来的这批票**彼此之间高度一致**
（1,245 只全部挤在"ROE 最低 + 收益最低"这个角上）：

* 它们两两之间是**同序对（concordant）**，会把 ρ 往 **正** 方向拉；
* 本样本的 ρ 本来就是弱负（−0.047），被这团同序质量一拉就朝 0 靠；
* 分位差同向变化：Q1 的均值收益被这批 −63% 拉低，于是 `Q5−Q1` 从 −0.0601 升到 −0.0486。

**经济含义**：原数据说"高 ROE → 未来收益更低"（负向因子）；
把退市股放回来之后发现"**极低 ROE 的那一端同样是灾难**"——
这恰恰是**反方向**的证据，于是负向关系被显著削弱。

## 四、结论修正 ★

> **原先的"ROE 是个负向因子"有相当一部分是存活偏差的产物。**

| 说法 | 之前 | 现在 |
|---|---|---|
| ROE 因子的方向 | 负向（高 ROE → 低收益） | 负向但**大幅减弱** |
| h=252 RankIC | −0.0589 | **−0.0395**（衰减 33%） |
| h=252 Q5−Q1 | −0.0736 | **−0.0486**（衰减 34%） |
| 显著性 | BHY 校正后不显著 | **更加不显著**（\|t\| 只会更小） |

**"ROE 在 A 股月频上不构成显著因子"这个结论不变，而且更稳。**
但原因变了：不再只是"统计功效不足"，而是**效应本身就比原先测到的小三分之一**，
其中一部分原本是存活偏差伪造出来的。

## 五、方法论收获（可复用到任何因子）

1. **补数据 ≠ 修好偏差。** 把退市股加进行情和财务只是第一步；长持有期的前向收益
   在退市处**结构性缺失**，不引入显式约定，IC 会一直看到被截断的子样本。
   （实测：退市股最后 3 个调仓日的 h=252 实现率只有 **14%**，在市股 86%。）
2. **约定必须显式、可切换、进台账。** 三种约定、`delist_filled` 计数、
   停牌与退市的区分，全部落在契约与台账里，而不是藏在 `dropna` 里。
3. **秩相关对"联合极值簇"不敏感。** 一团挤在双低角的样本会把 ρ 往正方向拉。
   判断这类"灾难性下行"效应，除了 IC 还应看**分位差**与**尾部统计**
   （这也是 M2 里要给 `inference/` 补尾部指标的原因）。
4. **方向可以先猜，但必须以实测为准。** 本次两个方向的猜测都被推翻了一次：
   `体检层报告` 猜"退市股会加强信号"（错），本节又发现"补上后更弱"的机制
   不是数据质量而是统计量本身的性质。
